## 📖 Sobre

Jogo estilo bubble/crash em PHP com apostas via PIX (Ecompag), painel administrativo em `/admin` e gestão de rodadas e usuários.

## ✨ Recursos

| Módulo | Descrição |
|---|---|
| Jogo | Bubble/crash com multiplicador |
| PIX Ecompag | Depósitos e saques |
| Admin | Painel em `/admin` |
| Configuração | Banco no `.env` |
| Histórico | Rodadas e resultados |
| Usuários | Cadastro, saldo e histórico |

## 📦 Instalação

1. Envie os arquivos para a hospedagem (PHP 8+ e MySQL/MariaDB).
2. Crie o banco e importe o SQL do pacote.
3. Configure o banco no `.env`.
4. Acesse `/admin` com `admin@eu.com` / `qwe123#` e **troque a senha**.
5. Configure as credenciais da [Ecompag](https://ecompag.com).
